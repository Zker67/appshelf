# 阶段 03：界面

状态：`[done]`（界面效果由用户在阶段 07 检查）

## 目标

用 MyGo 原生 UI 做出主界面、软件编辑和设置页，把阶段 01、02 串成用户能直接使用的版本。只用 MyGo 自带组件和主题，跟随系统深浅色；界面文案保持简短。

## 窗口与页面

一个主窗口，用页面路由在三个页面之间切换：**软件**、**任务**、**设置**。窗口位置用 `StateKey` 记住。

## 软件页

```text
┌──────────────┬────────────────────────────────────────────┐
│ 全部          │ [添加软件]                     [检查更新]   │
│ 分类          ├────────────────────────────────────────────┤
│ ☐ 开发工具    │ ☐ 名称          分类      标签   来源   状态 │
│ ☐ 设计        │ ☐ VS Code       开发工具  AI    winget 已安装│
│ 标签          │ ☐ Obsidian      效率            winget 未安装│
│ ☐ AI          │ ...                                         │
│ ☐ 常用        ├────────────────────────────────────────────┤
│              │ 已选 2 项        [全选] [安装] [更新]          │
└──────────────┴────────────────────────────────────────────┘
```

- **左侧栏**（`Sidebar`）：“全部”，以及每个分类和标签，前面带勾选框。多选时取并集；不勾选时显示全部。
- **软件表格**（`Table`，`Selection` 多选）：名称、分类、标签、来源、状态。状态列按“可更新 / 未安装 / 已安装 / 未知”显示，可按任意列排序。“未知”时显示原因。
- **双击某一行**：打开编辑对话框。
- **底部栏**：已选数量；“全选”选中当前筛选结果里的全部软件；“安装”和“更新”打开预览。
- **启动后**：先显示清单，再在后台查询状态，查询期间状态列显示加载中。

## 预览对话框（`Modal`）

列出每个选中的软件将要发生的事，确认后才放进队列：

| 软件 | 来源与精确 ID | 将执行 |
|---|---|---|
| Obsidian | winget `Obsidian.Obsidian` | 安装 |
| VS Code | winget `Microsoft.VisualStudioCode` | 跳过：已安装 |
| Foo | scoop `extras/foo` | 不可用：未安装 scoop |
| Bar | winget `Bar.Bar` | 跳过：无法确认状态 |

只有“将执行”为安装或更新的项会进入队列。GitHub 来源会额外显示将要下载的安装包文件名和版本。

## 任务页

队列的每一项一行：软件、动作、状态、失败原因。失败的项可以“重试”，也可以打开日志；顶部有“停止”（当前项执行完后停止）。

## 编辑软件对话框

- 字段：名称、分类（`Select`）、标签（`CheckboxGroup`）、来源类型、来源字段、检测规则。
- winget 和 scoop：输入关键字后用来源的 `Search` 查找，从结果里选中后填入精确 ID，不让用户手打 ID 后直接保存。
- GitHub：填写 `owner/name`、可选的安装包匹配规则和安装参数；检测规则必填。
- 保存时执行阶段 01 的校验，不通过时在对应字段下显示原因。
- 删除软件需要二次确认。

## 设置页

- **来源状态**：winget（以及 `Microsoft.WinGet.Client` 模块）、scoop、GitHub（是否检测到 token，剩余请求额度）。winget 缺少模块时显示“安装模块”按钮，确认后执行 `Install-Module Microsoft.WinGet.Client -Scope CurrentUser`。
- **分类与标签**：添加、重命名、删除。删除前提示受影响的软件数量。
- **导入 / 导出**：阶段 05 接入。
- **关于**：版本号、检查 AppShelf 更新（阶段 05 接入）。

## 成功标准

- 视图测试（`ui.NewTester`）：勾选分类后表格只显示对应软件；多选取并集；全选后数量正确；预览里已装的项显示为跳过；编辑对话框校验失败时不能保存。
- `go tool mygo dev` 能启动，并显示本机真实清单和状态。界面效果由用户在真实窗口里检查，AI 不截图自验。

## 失败与回滚

某个组件在原生 UI 里实现困难时，先在本文件记录原因和替代方案（例如改用 `List` 加 `Checkbox`），不改用 Web 页面窗口，除非用户同意。
