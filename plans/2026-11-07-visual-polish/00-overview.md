# 视觉质感与切换动效

状态：`[in-progress]`：实现与自动检查完成，真实窗口效果待用户验收。

## 目标

用户反馈界面“太素、不够现代化”，要求以应用图标为基准提升高级感和切换的动态感。只补样式和动效，不加功能、不改布局和操作顺序。

## 视觉母题（取自图标）

- 深钴蓝 → 天蓝的斜向渐变：用于主按钮、顶栏选中页签、勾选框和开关的选中态、空状态图标块。
- 玻璃质感：左侧栏和顶栏半透明，透出窗口左上角的环境光晕；下拉、右键菜单、弹窗、提示用半透明底加背景模糊。
- 星光：空状态图标块右上角一颗闪烁的四角星。

## 实施

1. `src/index.css`：新增品牌渐变、带色阴影、遮罩、环境光 token（亮暗两套）；`--sidebar`、`--titlebar` 改半透明；窗口背景加环境光晕。
2. 全局组件（只用 `data-slot` 选择器覆盖，不改 `components/ui/` 的结构）：主按钮渐变与按压回弹；勾选框、开关选中渐变；菜单、弹窗、侧滑面板的玻璃底和弹性入场；遮罩模糊；骨架屏流光；分栏拖拽线悬停高亮。
3. 切页：`App.tsx` 按页签顺序判断方向，页面从对应一侧滑入。
4. 顶栏：选中页签滑块改成品牌渐变，弹性跟随；图标悬停轻微转动。
5. 左侧栏：选中态不用左侧竖条，改为浅色渐变底加细边框，数量变成品牌渐变胶囊，图标微放大，整行轻弹；未选中行悬停时图标轻跳一次。
6. 列表：三页的行前 16 行级联入场；悬停时软件图标轻微上浮；选中行不用竖条，改为内缩的圆角浮起卡片，弹性出现。
7. 本机已装概览：统计块依次入场、悬停抬升、数字滚动；来源分布和覆盖进度条从左长出。
8. 详情栏：头部、操作、正文依次滑入。空状态：渐变图标块缓慢浮动，星光闪烁。
9. `prefers-reduced-motion` 下沿用现有规则关闭动效。

## 不变量

- 只改展示，不改 Go 服务、数据、筛选和操作逻辑。
- 已有的页签图标动画、选中态、提示位置保持不变。

## 验收

- `bun run --cwd frontend check`、`bun run --cwd frontend test` 通过。
- 用户在真实窗口亮暗两套主题下确认：质感、切页方向、侧栏和列表动效、概览动效、弹窗和菜单。

## 回滚

改动只在 `frontend/src` 和文档，按文件撤回即可。
