# 阶段 01：UniGetUI 功能对照表

状态：`[done]`（2026-11-07 整理）

对照依据：UniGetUI README 的功能列表，以及源码 `src/UniGetUI.Avalonia/Views/SoftwarePages/`、`src/UniGetUI.PackageEngine.PackageLoader/`、`src/UniGetUI.PackageEngine.Managers.WinGet/`、`src/UniGetUI.Core.IconStore/`（main 分支，2026-11-07 读取）。

取舍原则：以 AppShelf 的原始需求为准，加上用户这次要求的两点，即识别本机已有软件、方便地搜索和加入清单；不追求功能齐全。

## 对照表

| # | UniGetUI 功能 | UniGetUI 的做法 | AppShelf 0.1.0 | 本计划 |
|---|---|---|---|---|
| 1 | 已装软件页 | 汇总所有包管理器的已装软件，包括 winget 没关联到源的“本机”项（ARP）和 Microsoft Store 应用（MSIX） | 无：只显示清单里的软件 | **采纳**：“本机已装”页，来源为 winget、scoop、注册表（[03](./03-installed.md)） |
| 2 | 已装软件与来源关联 | winget 自己把注册表项关联到包 ID；按卸载键、UpgradeCode、ProductCode、名称加发布者依次匹配 | 只判断清单里的软件是否已装 | **采纳**：已装项标出对应的 winget ID 或 scoop 软件，以及是否已在清单；“本机”项提供“查找来源” |
| 3 | 发现软件（搜索） | 同时搜索所有启用的包管理器，合并结果，可按来源筛选 | 编辑框里按来源分别搜索，一次加一个 | **采纳**：一个搜索框同时搜 winget、scoop、GitHub（[04](./04-discover.md)） |
| 4 | 多选批量操作 | 选中多个包后一起安装、更新、卸载 | 清单里多选后安装、更新 | **已有并扩展**：搜索结果和本机已装列表也能多选，批量加入清单 |
| 5 | 软件详情 | 发布者、作者、简介、主页、许可证、发行说明、标签、安装程序地址和哈希、大小 | 无 | **部分采纳**：图标、简介、发布者、主页、许可证、最新版本、发行说明链接。不显示安装程序地址、哈希和大小 |
| 6 | 图标 | 自建图标库（按规则把包 ID 转成键名）、winget 清单里的图标、注册表 DisplayIcon、MSIX 资源 | 无 | **采纳**：UniGetUI 图标库、注册表图标、GitHub 头像，最后用首字母兜底（[05](./05-icons.md)） |

| 8 | 检查更新 | 已装软件统一检查，更新页列出全部可更新项 | 清单里的软件检查更新 | **已有**；本机已装页显示“可更新”标记，清单外的软件是否允许直接更新，待用户决定 |
| 9 | 安装、更新 | 一键安装、更新，操作队列，失败可用管理员身份或交互式重试 | 预览后逐个执行，执行前后复查，失败可重试 | **已有**；不加“以管理员或交互式重试” |
| 10 | 卸载 | 支持 | 无 | 不做（原非目标） |
| 11 | 忽略更新、跳过版本 | 按包忽略全部更新或某个版本，可设时限 | 无 | 不做（原非目标） |
| 12 | 自动更新、定时检查、通知、托盘 | 定时检查、自动安装、Toast 通知、托盘显示更新 | 无 | 不做（原非目标） |
| 13 | 安装选项 | 每个包单独设置安装参数、版本、架构、范围、位置，并保存用于以后更新 | GitHub 来源可以填安装参数 | 不扩展 |
| 14 | 软件合集（Bundle）导入导出 | 导出软件列表，含安装参数，可在新电脑导入安装 | 清单导入导出（合并），含分类和标签 | **已有** |
| 15 | 备份与云同步 | 本地备份、同步到 GitHub Gist | 无 | 不做 |

## AppShelf 自己有、UniGetUI 没有的

| 功能 | 说明 |
|---|---|
| 分类和标签 | 一个软件一个分类、多个标签；按分类或标签多选筛选（取并集） |
| 清单驱动 | 清单是自己维护的“想装哪些软件”，可以在新电脑上一次装齐 |
| GitHub Releases 来源 | 按 GitHub Store 的方式选安装包，校验 SHA-256，检测规则认出已装 |
| 防误装复查 | 执行前后都重新检测；检测规则认出“来源外安装”，不重复装 |

## 本计划因此新增的能力

1. “本机已装”页（第 1、2 项）。
2. 统一搜索和一步加入清单（第 3、4 项）。
3. 软件详情和图标（第 5、6 项）。

其余都是已有能力或不做。
