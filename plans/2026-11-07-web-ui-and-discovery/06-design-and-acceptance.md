# 阶段 06：视觉打磨、自测与用户测试

状态：`[partial]`：已实现，用户验收与运行验证边界见 [实施报告](./09-implementation-report.md)。

## 视觉方向

整洁、紧凑、信息清楚的桌面工具，接近现代应用商店加软件管理器的感觉；不做花哨装饰。

| 项 | 规定 |
|---|---|
| 布局 | 左侧固定导航（我的清单、发现、本机已装、任务、设置），宽约 200 像素，窄窗口时收成图标；顶部一条：页面标题、全局搜索框、页面操作按钮 |
| 列表行 | 32 像素图标；两行文字：名称，下面是发布者 · 来源 ID；右侧是状态标签和操作按钮；悬停高亮，选中有勾选框和底色 |
| 详情 | 右侧滑出面板，不打断列表；Esc 关闭 |
| 颜色 | shadcn Nova 的中性色加一个主色；状态颜色固定：可更新为主色，已安装为绿色，未安装为灰色，未知为琥珀色，不可用为浅灰色；跟随系统深浅色 |
| 字体 | 系统字体：Segoe UI Variable，中文用 Microsoft YaHei UI；数字和 ID 用等宽字体 |
| 动效 | 只用 CSS 过渡：面板滑出、按钮状态、列表项加入；不引入 Motion |
| 空状态 | 一句话加一个主要按钮，例如清单为空时“去发现软件”和“导入清单” |
| 加载 | 列表用骨架占位；搜索中在对应来源组标题旁显示转圈 |
| 文案 | 中文，简短；按钮用动词；错误写原因和处理办法，不写长说明 |

## 键盘

| 按键 | 作用 |
|---|---|
| `Ctrl+F` 或 `/` | 聚焦当前页的搜索或过滤框 |
| 回车（发现页） | 同时搜 GitHub |
| 空格 | 勾选或取消当前行 |
| `Ctrl+A` | 全选当前结果 |
| Esc | 关闭面板、弹层和对话框 |

## 交付前 AI 自测

1. `gofmt -l .`、`go vet ./...`、`CGO_ENABLED=0 go test ./...`；前端类型检查、lint、单元测试。
2. `go tool mygo build` 生成带前端的安装包；启动构建出的程序，确认正常运行、关闭后正常退出（不截图）。
3. 同步文档：`README.md`、`AGENTS.md`、`docs/api.md`、`docs/operations.md`、`docs/architecture/project-structure.md`、`internal/README.md`、`references/`。
4. 写 `09-implementation-report.md`。

界面效果不由 AI 截图自验，由用户在真实窗口里检查。

## 用户测试清单

用 `go tool mygo dev` 测试，或安装 `build/` 里的 0.2.0 安装包。

| # | 场景 | 预期 |
|---|---|---|
| 1 | 首次启动 | 清单为空时提示去“发现”或导入清单；设置页显示各来源状态 |
| 2 | 搜索 | 在“发现”输入 `obsidian`，约 1 秒内出现 winget 结果，每项标出“本机已装”或“已在清单” |
| 3 | 一步加入 | 点“加入”，选分类、标签（可直接新建），确认后在“我的清单”出现，来源是精确 ID |
| 4 | 批量加入 | 勾选 3 个结果后“加入清单”，一次设好分类和标签 |
| 5 | 加入并安装 | 加入后直接出现安装预览，确认后逐个安装 |
| 6 | GitHub | 按回车搜 GitHub，打开详情能看到将安装的安装包；加入时自动给出检测规则 |
| 7 | 查不到 | “手动添加”打开编辑框，名称已填入搜索词 |
| 8 | 详情 | winget 软件显示简介、发布者、主页、许可证 |
| 9 | 本机已装 | 列出本机软件；已在清单的标出；winget 项可直接加入；可按来源筛选、只看未加入的 |
| 10 | 查找来源 | 对一个“本机”项点“查找来源”，选中结果加入后，它在清单里显示为已安装，不会被重复安装 |
| 11 | 图标 | 常见软件显示真实图标，没有的显示首字母；滚动本机已装列表不卡顿 |
| 12 | 0.1.0 的功能 | 分类和标签管理、筛选取并集、批量安装跳过已装、失败重试、停止、检查更新、导入导出，都与 0.1.0 一致 |
| 13 | 防误装 | 断网时不会装错；来源外安装的软件显示“已安装（来源外）”，不重复安装 |
| 14 | 外观 | 深浅色都清楚；窗口缩小时布局不乱 |
| 15 | 自更新 | 发布 0.2.0（需要授权）后，已安装的 0.1.0 提示更新并成功升级到 0.2.0 |

测试中发现的问题记到 `09-implementation-report.md` 的遗留项，或另开计划。
