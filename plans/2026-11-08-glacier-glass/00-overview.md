# 冰川蓝 · 轻玻璃

状态：`[in-progress]`

## 目标

用户要求视觉方向重做为「冰川蓝 · 轻玻璃」，在现有基础上大改观，精致、现代化；明确不怕改动面大。只改展示，不改功能和操作顺序。

## 方向

- 配色：主色从偏紫的钴蓝（色相 264）换成冰川蓝（色相约 235），品牌渐变为冰川蓝 → 冰青；中性色带一点冷蓝。单页大体三种颜色：冰白 / 极夜蓝灰底、冰川蓝点缀、少量状态色。
- 质感：轻玻璃。不靠发光，靠 135° 渐变细边、顶部内高光、两层柔和投影；去掉原来主按钮、计数胶囊的蓝色发光。
- 布局：窗口底是一张缓慢流动的冰雾背景（第 8 条曾改为静止，第 11 条恢复）；顶栏透明融入背景；各页的侧栏、列表、详情改为浮在背景上的玻璃面板，面板之间留缝，缝兼作拖拽条。
- 形状：面板圆角约 16px，控件 8–10px；胶囊只给导航选中项、徽标、分段切换。
- 动效：现有的导航图标动画、切页滑入、列表级联、弹簧曲线全部保留，按新配色重新调色。

## 借鉴

[crenspire/glass-ui](../../references/external-repos/crenspire__glass-ui/README.md) 的 CSS 材质层思路：材质（`regular` / `clear` / `tinted`）× 用途（面板、弹层、工具条、控件、行内），渐变细边，三层光影，`prefers-reduced-transparency` 降级，Chromium 下的 SVG 透镜滤镜。只借思路，用本项目的 oklch token 重写；不装它的组件（会覆盖 `components/ui/` 生成的 radix-nova 组件，尺寸体系和依赖都不合），不用 WebGL 折射。

## 实施

1. `[done]` token：`src/index.css` 亮暗两套重写；新增 `--glass` / `--glass-strong` / `--glass-float`、`--glass-edge`、`--rim-hi` / `--rim-lo`、`--hover`、`--track`、`--thumb`、`--field`、`--sticky`、`--selected` 和冰雾 `--fog-*`；`--border`、`--input`、`--card` 改为半透明，放在任何玻璃上都一致。组件里直接写的色值（`bg-foreground/[0.045]`、`dark:bg-white/[0.05]`、`shadow-black/10` 等）全部换成 token；去掉不再使用的 `--titlebar`、`--ambient-*`。
2. `[done]` 材质层：`src/index.css` 的 `@layer components` 里 `glass-panel`（面板，`glass-strong` 加密）、`glass-float`（浮在面板上、带背景模糊）、`seg-track` / `seg-thumb`（分段切换）。渐变细边用 `::after` 加遮罩只画 1px 的环，压在内容之上。生成的 `components/ui/` 仍只通过 `data-slot` 换装。原计划的 `src/lib/glass.ts` 没写：几个类就够用，不需要再包一层。
3. `[done]` 背景：`App.tsx` 的 `.ice-fog`，渐变底加三团雾。最初缓慢漂移（46–72 秒往返），用户反馈字体发虚后改为静止，见第 8 条。
4. `[done]` 外框：顶栏透明；页面四周留 8px，分栏改为玻璃面板，拖拽线改为 8px 缝隙，悬停和拖动时出现主色把手；`react-resizable-panels` 的组和面板内层改 `overflow: visible`，面板自己裁切，投影不被切掉。侧栏、列表、详情面板，表头、吸顶分组头，列表行（内缩分割线、内缩悬停和勾选底）、聚焦行和侧栏选中项（同一张浮起的冰面卡片），批量操作条、搜索框、外框按钮逐个换装。
5. `[done]` 浮层：菜单、弹窗、侧滑面板、Toast 统一为 `--glass-float` 加背景模糊、细边和顶部高光。
6. `[dropped]` 透镜：面板后面是平滑的渐变雾，SVG 透镜和背景模糊在上面都看不出差别，反而要在雾漂移时每帧重算；面板因此只用半透明，不加背景模糊，模糊只留给浮在内容上的弹层、批量操作条和吸顶分组头。
7. `[done]` 文档：`frontend/README.md` 的外观约定。
8. `[done]` 文字清晰度（用户反馈字体不清晰、标题不好看）：WebView2 的 Chromium 只给画在不透明图层里的文字用 ClearType；漂移的雾被提升为 GPU 图层后，压在它上面的半透明面板和顶栏也被拆成透明图层，文字退回灰度抗锯齿。改为：雾静止且不再单独成层；列表和详情面板（`glass-strong`）改为不透明的冰白（取原半透明叠在雾上的颜色），发现页吸顶分组头不透明、去掉模糊；弹窗和侧滑面板恢复不透明底（遮罩已模糊背景）。侧栏保持半透明。顶栏标题改为 15px 粗体、字距 0.04em，图标 24px。
10. `[done]` 字体与字重（用户反馈字体和字重仍需优化）：本机显示缩放 150%，Chromium 在这个缩放下本来就用灰度抗锯齿，第 8 条的 ClearType 分析对这台机器不成立，发虚主要来自中文字体：微软雅黑只有常规和粗体，`font-medium`（500）按常规显示、`font-semibold`（600）按粗体显示，层次不足又显粗糙。改为中文优先 Noto Sans SC（本机已有的可变字体，100–900），没有时退回微软雅黑 UI；标题用 Segoe UI Variable Display；顶栏标题改为半粗、字距 0.03em；列表和详情的版本号从 Cascadia Mono 改为普通字体加等宽数字；修正 `body` 的 `"tnum" 0` 让 `tabular-nums` 失效的问题。
11. `[done]` 更纱黑体与恢复流动（用户确认）：冰雾恢复漂移，列表和详情面板、吸顶分组头恢复半透明（第 10 条已查明发虚与流动无关）；弹窗和侧滑面板保持不透明。界面字体改为随程序打包的更纱黑体 UI 简体（`frontend/public/fonts/`，Sarasa-Gothic v1.0.43，常规 / 半粗 / 粗体三个字重，按 ASCII、拉丁、常用符号、GB2312 全部字符和界面源码里出现的字裁成 WOFF2 子集，每个约 1 MB，附 OFL 许可证原文和中文 README）；`font-medium` 映射到半粗。
12. `[done]` 顶栏去掉「软件图书馆」文字（用户要求），只留应用图标，图标的替代文字为「软件图书馆」；窗口标题不变。
9. `[done]` 窄列工具条：中间列变窄时右侧按钮被裁掉。新增 `WideLabel`（`components/common.tsx`），按列表面板宽度（容器查询 `@xl` / `@2xl`）收起按钮文字，只留图标和悬停提示；左侧标题允许截断。

## 不变量

- 不改 Go 服务、数据、筛选和操作逻辑；不新增依赖。
- 已有动效不减；选中态不用左侧竖条；Toast 仍在顶部正中。
- 亮暗两套都要可读：浅色下分割线、选中态、面板边界清楚。
- 背景模糊只用在浮在内容上的东西（弹层、批量操作条、吸顶分组头），面板、行和徽标不加模糊。
- 应用图标不改（用户未要求）。
