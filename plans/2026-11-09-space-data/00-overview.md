# 软件数据目录空间统计

状态：`[in-progress]`

## 目标与范围

空间统计独立识别数据目录，不使用卸载残留的可清理评分。覆盖应用包 PackageFamily、scoop persist、Local/Roaming/LocalLow/ProgramData 下的软件名称与发布者子目录，结合注册表名称、安装目录和程序图标文件名补充名称线索。只统计匹配目录，不扫描整个磁盘或任意包含名称的目录。

## 不变量与风险

- 不改变卸载或残留清理规则；空间结果只供显示和打开位置。
- 不因目录含 DLL 或文件多而隐藏；排除安装目录重叠、其他软件安装目录、受保护目录，父子目录及重复路径只计一次。
- 名称推测仍可能不完整，界面显示“已统计占用”，不承诺涵盖自定义数据位置；读取失败须标明部分统计。

## 实现与验证

1. 新增独立的只读数据目录查找入口，接入 Installed.Space。
2. 覆盖大目录、应用商店包、发布者层级、别名、scoop persist、保护目录与去重的回归测试。
3. 运行 Go、前端检查与 MyGo 打包；本机只读核对 Dia、Docker 等目录。真实窗口由用户验收。
4. 更新 API 文档与计划索引。

## 回滚

回退本计划对应的空间查找、接口文案和测试修改即可；无数据迁移。

## 实施结果

- 已接入独立 `FindData`，保留残留清理原评分；补齐应用包、发布者层级、名称别名和 scoop 安装范围，过滤重叠及重复路径。
- 空间测量可取消，跳过链接及无法读取的文件时返回 `partial`；文案改为“已统计占用”，空结果不表示没有数据。大小按文件逻辑长度合计，不等同于文件系统实际分配空间。
- 本机只读验证：Dia 数据约 191 MiB，Bitwarden 约 6.8 MiB；Docker Local 数据约 53.5 GiB，另有 Roaming 和 ProgramData 数据，Local 统计标记为部分结果。未卸载、安装或清理这些软件。
- 完整 `CGO_ENABLED=0 go test ./...` 通过；最终空间定向回归通过；`go vet ./...`、`go tool mygo vet`、前端 check、64 项前端测试、MyGo 打包通过。
- 另一次 API 全包复跑中，既有 `TestSearchRealWinget` 因 browser 首批耗时约 10 秒超过 5 秒断言而失败；该测试未改，本次空间回归通过。
- `gofmt` 检查本次 Go 文件通过；全库列出的 37 个旧文件仅为 CRLF 换行差异，已验证没有格式内容差异并保留原换行，未纳入改动。
- 可运行产物：`build/windows-amd64/AppShelf.exe`；未发布，真实窗口待用户确认 Dia / Docker 的数据目录、大小和打开位置。
